# TLS edge for opt-in reviewer demo

The repository will add an opt-in TLS reviewer demo as a `compose.tls-demo.yaml` overlay, leaving `make demo` as the intentionally HTTP-only trusted-local path. Caddy will be the sole public gateway entry point: host port `8080` returns a `308` redirect to HTTPS on `8443`, and Caddy forwards only `/v1/`, `/healthz`, and `/readyz` to the gateway on the private Compose network. The gateway has no published host port in this mode; `/metrics` remains on its separate private listener for Prometheus and is never proxied. Caddy will create Docker-managed local development CA and leaf material, which the TLS smoke test trusts explicitly without committing keys or requiring system trust. Gateway request-size and timeout policy remains authoritative, with compatible edge ceilings; it will not consume forwarded headers until a concrete feature and trusted-proxy policy require them. The TLS smoke runs in pull-request CI and proves the HTTPS payment flow, the HTTP redirect, the absent public metrics route and direct gateway host port, and the continued private Prometheus scrape. mTLS, public certificate issuance and renewal, hosted deployment, and TLS in the Go process remain out of scope; non-local certificate lifecycle and network access controls belong to the deployment platform.
