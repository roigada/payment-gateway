# v1.0.0 release notes — draft

> Status: draft only. Do not tag or publish this release until the YouTube walkthrough is linked from the README and all quality gates pass.

## Payment Gateway portfolio milestone

`v1.0.0` marks a portfolio milestone for the Payment Gateway demo. It is a stable presentation point for the repository, not a promise of long-term public API compatibility. The OpenAPI contract remains demo-scoped.

### Highlights

- A reviewer-first README with a recovery sequence diagram and a short backend walkthrough.
- A runnable local Docker demo, OpenAPI contract, HTTP collection, Prometheus/Grafana signals, and TLS edge smoke path.
- Durable Idempotency Replay and recovery of a Stuck Idempotency Claim using a persisted Bank Operation Key, avoiding duplicate Mock Bank side effects.
- Quality gates for tests, `go vet`, `govulncheck`, API validation, observability validation, Compose smoke paths, and production-image smoke testing.

### Scope

The authored implementation is in `gateway/`. `mock-bank/` is bundled third-party demo infrastructure; see its provenance documentation. This release does not represent a hosted payment product or a real payment-provider integration.
